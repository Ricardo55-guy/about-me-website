:null is a gnu-free hybrid android / linux distribution based on x86_64 blissOS 16, but with all UI framework stripped out, and replaced with a tty. 
alongside bionic to keep the android services like init running, as well as the main point of the distro, having actual package support without gnu, bionic is installed alongside a musl and pkgsrc layer.
it also includes many package replacements like mksh instead of bash, and some more.
